# 发布格式教学：标注样本、批量预览、保存复用

发布格式教学用于**普通剧集的文件名字段抽取**：作品已知，但陌生发布方式让标题、原始集号或修订版混在一起时，可以不写正则、不改代码，教给现有识别器一个有明确范围的模板。

它不是第二套识别引擎，也不执行整理、改名、下载或 TMDB 绑定。**模板字段通过，不代表 TMDB 身份或最终归档结果已经验证。** 后续仍使用原来的身份核验、人工锁、预处理、剧集映射与写入确认流程。

## 1. 推荐：让 Agent 帮你配置

打开 **整理规则 → 识别与命名 → 发布格式教学 → 让 Agent 帮我识别**，或直接在 Media Agent 对话中提出需求。使用前需要启用 Agent 并配置可用模型；可从 Agent 输入框旁的设置按钮进入。

你不需要填写模板。把至少两个真实文件名贴给 Agent，说明正确的剧名、原始集号和所在目录即可。例如：

> 这两个文件在 `/Anime/Teaching`，标题都是“星海航行”，分别是第 13、14 集。r2 是修订版，不是第 2 集。请帮我学会这个格式，先预览，再让我确认保存。
>
> `[Example-Team][星海航行][track013r2][1080p].mkv`
>
> `[Example-Team][星海航行][track014r2][1080p].mkv`

流程是：

1. **Agent 代填格式**：从你提供的样本推导标题、集号和修订版的位置；信息不足时先追问，不应编造样本或让你写模板。
2. **系统真实预览**：使用与原手工教学相同的解析器和样本检查，核对纠正前后的标题、季集、未匹配和冲突。若你只说“先预览，不要保存”，这一阶段不会创建保存计划。
3. **你核对后确认**：只有出现系统确认卡，并点击确认，才会保存规则。“已预览”或 Agent 的文字回答不代表已经保存。
4. **以后自动复用**：保存后，同范围、同格式的新识别使用该规则；不会立即重跑旧任务、改名或移动文件。

页面入口只会把引导文字放进对话输入框，**不会自动发送，也不会覆盖已有草稿或替你执行待确认计划**。请把示例替换成自己的真实文件。文件名及对话会交给你配置的 Agent 模型处理，但教学工具本身不会上传或读取视频内容。

默认先限定当前目录。请核对确认卡中的样本与范围，尤其不要把猜测的剧名、修订号或换算后的季内编号当成已确认事实。模板由模型生成并不意味着样本标注一定正确。

## 2. 高级：手动教学（可选）

只想手动维护时，从同一位置进入“高级手动配置”。普通用户使用上一节的 Agent 流程即可，不必理解下面的模板语法。

以下是合成示例，可以先用它理解流程，再替换为自己的文件名：

```text
[Example-Team][星海航行][track013r2][1080p].mkv
[Example-Team][星海航行][track014r2][1080p].mkv
```

填写模板：

```text
[Example-Team][{title}][track{episode}r{version}][{resolution}].mkv
```

也可以把文件名复制进模板输入框，选中一个片段，再用字段按钮替换为对应槽位。

标注两个样本：

| 样本 | 标题 | 原始集号 | 原始季号 |
|---|---|---:|---|
| `track013r2` 所在文件 | 星海航行 | 13 | 未显式提供时留空 |
| `track014r2` 所在文件 | 星海航行 | 14 | 未显式提供时留空 |

标题请填写文件名中希望抽出的原始标题片段，不要替换成另一语言的译名或 TMDB 展示名；作品别名与 TMDB 绑定仍使用原有功能。

这里 `r2` 是修订版，**不要把它标成第 2 集**。同样，不要把发布第 13 集直接标成 TMDB 第二季第 1 集：编号转换由既有剧集映射处理，不属于格式教学。

至少需要两个不同文件、两个不同集号，最多八个标注样本。若模板包含 `{season}`，每个样本都必须标注原始季号。

### 支持的字段

| 字段 | 含义与范围 |
|---|---|
| `{title}` | 标题，必填，最多 180 字符 |
| `{episode}` | 原始集号，必填，1–9999 |
| `{season}` | 文件名中的原始季号，可选，1–99 |
| `{version}` | 修订版数字，可选，1–99；`v`/`r` 前缀保留为字面量 |
| `{resolution}` | 常见清晰度，如 720p、1080p、2160p、4K |
| `{checksum}` | 8–64 位十六进制校验字段；不是作品身份凭据 |

其它内容按**字面量**匹配，包括发布组、标点和扩展名。每种字段只能出现一次，两个字段之间必须保留分隔字符；不能用任意正则或通配符省略整段结构。须保留视频扩展名，如 `.mkv`；字幕、图片等伴随文件不参与教学。

## 3. 批量预览并确认

在批量文件名区域每行粘贴一个文件名，单次最多 100 个。无需提供文件内容，也不会读取或改动这些文件。

预览会分别展示：

- 不含草稿格式的基线字段与应用后的字段（复查相同的已保存格式时，基线排除该格式，以展示它提供的改善）；
- 匹配但没有变化的文件；
- 不属于该格式或目录的文件；
- 特别篇等被保护的文件；
- 多个格式给出不同解释，或模板与明确季集编号冲突的文件。

SP、NCOP、NCED、访谈和特别篇目录等内容不会强套普通剧集模板。原文件及目录中的明确季集信息不能被模板中的矛盾数字覆盖；此类冲突会保留原始字段并要求确认，不会继续自动匹配放行。

只有标注样本全部通过、有实际改善、且没有造成已知教学样本回退时，才能确认保存。系统会回放已有启用规则的标注样本；这是一组**已知样本检查**，不是对所有未知发布名的正确率承诺。

如果样本本来已能正确识别，页面会提示没有改善，不再重复保存一条无必要规则。未匹配和被保护的批量项目会保留原有处理方式，不会从列表中悄悄消失。

格式预览最长有效 15 分钟；Agent 确认卡还受原有行动计划有效期限制，以先失效者为准。输入、规则库、进程或恢复状态发生变化后，需要重新预览。重复保存不会建立副本，不会重新启用已停用规则，也不会通过迟到请求复活已删除规则。

## 4. 目录限定与跨目录复用

默认选择“仅此目录”，填写识别链路实际使用的父目录上下文。按规范化后的路径精确匹配，**不递归到子目录**；不要把来源 ID 当成路径。

- 本地文件填写完整父目录，例如 `/Anime/Teaching`。
- 光鸭目录刮削使用“所选目录名/相对子目录”，例如 `Teaching`、`Teaching/Season 02`；单文件检查使用直接父目录名。
- 云端上下文不是目录 ID，也不保证不同扫描入口下的同名目录唯一。仅有目录名时，同名且同格式的文件也可能匹配；需要严格隔离时不要跨这些入口共用模板。

目录组检查仍独立核对文件本身的季集证据，不会为了使用模板而把根目录标题或季号灌入所有文件。

**建议先使用“仅此目录”。** 它适合验证当前一批文件，影响范围最容易核对。

选择跨目录的发布格式时：

1. 模板必须保留有意义的固定发布前缀，不能只有 `{title}-{episode}.mkv`；
2. 标注样本至少来自两个不同标题的已知作品；请核对它们不是同一作品的中外文别名，教学预览不会在线验证作品 ID；
3. 只复用字段结构，不复用作品的 TMDB ID、季号偏移或集号映射。

同一发布组可能采用不同格式；不同模板可以分别保存，但遇到矛盾解释不会凭创建顺序选一个结果。请缩小范围或停用冲突格式后重新教学。

## 5. 生效、停用与恢复

- 保存后会立即更新后续识别使用的规则快照。**不会重新执行历史整理任务**；需要重新扫描或预览，才能在新的识别结果中看到效果。
- 列表中可停用、重新启用或删除规则；停用和删除会立即停止后续复用。
- 重新启用也会核对已知样本冲突。修改格式内容时，先停用旧格式，再重新教学，避免静默改变已验证的规则。
- 规则和标注样本保存在本机数据库，随现有整库备份保存。手工教学不调用模型；Agent 模式使用你已配置的对话模型，规则校验和保存仍在本机完成。
- 本功能使用 schema 31。旧库由既有备份和事务迁移流程升级；恢复备份会使格式缓存及已有预览失效。**回退不支持 schema 31 的旧程序时，应同时恢复升级前的数据库备份**，不要让旧程序直接操作新库。

## 6. 第一版的边界

本功能不自动发现或猜测作品身份，不解决“只有随机文件名且无任何来源信息”的识别问题，也不承诺适配全部发布组。教学样本的标注质量和模板范围直接影响后续结果；请把“字段抽取正确”“TMDB 匹配正确”和“可以执行整理”分开核对。
