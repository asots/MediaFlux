# 首次安装

## 启动与创建管理员

保持正常启动方式，无需额外初始化命令、授权码或手动重启：

- **源码运行**：执行 `python mediaflux.py start`，打开 `http://127.0.0.1:1258/setup`。
- **Docker**：执行 `docker compose up -d`，打开 `http://<服务器IP>:1258/setup`。

全新实例填写管理员用户名、密码（至少 8 位）和确认密码。创建成功后直接转到 `/login`，使用刚设置的账号登录；业务服务在同一进程中启用，不会自动登录。

真正首次安装沿用正常运行目录和平台支持，不需要额外修改目录权限、设置初始化标记或调整平台白名单。自定义目录使用 `start --data-dir <目录>`；该参数不会覆盖已配置的 `MEDIAFLUX_CONFIG_DIR`。官方 Docker 默认把数据库和 `user.env` 放在 `/app/db`，请保留挂载卷。

源码首次启动默认监听回环地址；官方容器默认允许远程首次设置。需要远程完成源码安装时，可明确设置 `MEDIAFLUX_ALLOW_REMOTE_SETUP=1` 并选择监听地址；请使用可信网络或 HTTPS 入口。完成安装后的监听配置仍按现有 `WEB_HOST` / `--host` 规则处理。

## 已有安装与恢复异常

- **已有账号**：直接访问 `/login`；`/setup` 不会覆盖管理员。
- **已有数据库但缺少可用账号配置**：拒绝重新初始化，不会把原库当作空白实例重建。请找回原来的 `user.env` 或使用有效备份恢复。
- **配置损坏、未完成初始化或恢复文件异常**：停止写入并检查日志、备份与恢复状态；不要删除数据库、SQLite 附属文件、配置或恢复证据来绕过检查。

普通升级沿用现有数据库迁移和备份流程，不经过新建管理员流程。部署与备份操作见[部署指南](部署指南.md)。
